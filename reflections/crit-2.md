# Crit 2

## What was the breakthrough that moved the work forward?

Constantly having another agent critique the work of the main agent significantly improved the quality of the project. After the first prompt, the agent had built a (mostly) working redesign of the MyWay+ application - but I wasn't really happy with the design. I couldn't put it into words, it just wasn't what I envisioned. I opened a new instance and asked it to critique the current implementation. It gave very good feedback (**It's a marketing splash page, not a product.** The purple is the "default AI palette" tell.) which I completely agreed with. I fed this feedback back into the main, which made a new design which I was happy with it. As I added tweaks, I kept repeating this feedback loop, consistently improving the design/

## What did this work change about who I want to be as a software developer?

I've learned that AI agents are a lot like humans, I can't just shove massive tasks into Claude at once and expect a perfect result. The first pass took almost 2 hours to run and churned out a result I was not happy with, after giving it prompts with smaller scope - the output was much better. Like humans, tasks still need to broken down. Feedback loops seem to be a very important tool to improve the output of agents, in the future I will definitely do this for other tasks.
